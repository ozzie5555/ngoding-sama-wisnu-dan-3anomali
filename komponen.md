# Komponen Backend dan Database Website KEMBALI

**Backend (Server/Otak):** Bagian dari website KEMBALI yang bekerja di balik layar untuk menerima dan memproses setiap perintah dari pengguna. Ketika pengguna mendaftar, login, mengubah profil, mengajukan donasi, mengunggah foto barang, mengirim pesan, atau memantau status donasi, backend akan memeriksa identitas dan hak akses pengguna, memvalidasi data, menjalankan aturan sistem, kemudian mengirimkan hasilnya kembali ke website. Backend KEMBALI dikembangkan menggunakan layanan Supabase yang mencakup Supabase Auth untuk autentikasi dan session pengguna, PostgreSQL RPC untuk menjalankan proses donasi secara aman, Supabase Storage untuk menyimpan foto profil dan barang donasi, Supabase Realtime untuk memperbarui notifikasi, chat, ulasan, serta status donasi tanpa perlu refresh, dan Supabase Edge Functions untuk proses khusus seperti verifikasi Cloudflare Turnstile dan penghapusan akun. Backend juga mengatur pembagian akses antara donatur, manager komunitas, dan admin agar setiap pengguna hanya dapat menjalankan fitur sesuai kewenangannya.

**Database (Penyimpanan Data):** Bagian dari sistem KEMBALI yang berfungsi sebagai tempat penyimpanan seluruh data website secara terstruktur dan aman. Database KEMBALI menggunakan PostgreSQL yang tersedia pada Supabase untuk menyimpan data akun dan profil pengguna, pengaturan privasi, komunitas terverifikasi, kebutuhan komunitas, formulir dan foto donasi, riwayat perubahan status, notifikasi, ulasan pengguna, serta pesan chat komunitas. Setiap data saling dihubungkan menggunakan primary key dan foreign key sehingga, misalnya, sebuah donasi dapat diketahui siapa donaturnya, komunitas penerimanya, foto barangnya, dan seluruh riwayat statusnya. Keamanan database diterapkan menggunakan Row Level Security agar pengguna hanya dapat melihat atau mengubah data miliknya sendiri, sedangkan manager dan admin memperoleh akses sesuai tugasnya. Database juga menggunakan constraint, trigger, index, transaction, dan audit event untuk mencegah data tidak valid, mempercepat pencarian, menjaga konsistensi, serta mencatat setiap perubahan penting pada proses donasi.
